# Balatro MCP server

FastMCP tools for the local BalatroMCP Steamodded mod. Requires Python 3.11+.

From the repository root, install using: python -m pip install -e ./mcp_server

The game API defaults to http://127.0.0.1:8080. Override it with BALATRO_MCP_API_BASE_URL.
See the repository README for game setup.
